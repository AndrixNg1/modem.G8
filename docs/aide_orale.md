# Aide à la démonstration orale

- **Entropie** : compter les occurrences de chaque octet, diviser par la taille du fichier, puis calculer la somme -p log2(p). Un octet uniforme a 8 bits d'entropie ; un fichier constant en a 0. Un texte redondant se compresse, un PNG déjà compressé ou un fichier pseudo-aléatoire beaucoup moins.
- **Compression** : Qc = avant/après ; zeta = après/avant ; Gc = (1-zeta)*100. Un gain négatif indique un fichier plus gros. On transmet alors le fichier brut.
- **CRC** : registre de 16 bits initialisé à 0xFFFF ; chaque octet est XORé dans la partie haute. Pour chacun de ses 8 bits, décaler le registre et appliquer 0x1021 si le bit de poids fort était à 1. Masquer à 16 bits. Le polynôme correspond à x^16+x^12+x^5+1. Le CRC détecte les erreurs, ne les corrige pas. Il détecte toutes les erreurs simples, les rafales de longueur <=16, et toutes les erreurs doubles pour les longueurs de trames G8. Le test de référence donne 0x29B1.
- **8N1** : start 0, huit bits LSB first, stop 1. Rendement 8/10. **8E2** : start, données, parité paire, deux stops. Rendement 8/12. La parité paire est obtenue par somme des bits modulo 2.
- **HDLC** : fanion 0x7E, adresse 0x18, contrôle, longueur, données, CRC, fanion. 7 octets de service ; 48/(48+7) = 87,27 % sans stuffing. Le stuffing évite de confondre données et fanion ; plus de bits transmis, rendement inférieur.
- **Boucle locale** : compression éventuelle, en-tête, blocs, CRC, sérialisation, stuffing, extraction, destuffing, contrôle CRC, assemblage, décompression, SHA-256. Pas de son à cette étape. SHA-256 compare les contenus des deux fichiers et n'est pas le CRC utilisé pour chaque trame.
- **Simulation** : chaque bit est inversé avec une probabilité p ; 1-(1-p)^n est la probabilité qu'au moins un bit soit changé. Les rejets peuvent provenir d'un CRC incorrect ou d'une structure invalide. Les fluctuations sont normales pour 1000 essais.

À étudier dans les fichiers : `source.py` (entropie, entête), `crc.py` (boucles et opérations binaires), `trame.py` (sérialisation, stuffing, extraction), `transfert.py` (assemblage et intégrité), `mesures_module1.py` (simulation). L'enseignant peut interroger n'importe quel membre.
