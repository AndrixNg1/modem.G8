# Résultats commentés

Les CSV de `mesures/` sont générés avec la graine 2026. La prédiction d'erreur emploie la longueur réellement transmise de chaque trame, stuffing inclus : `Pe = 1 - (1-p)^n`. Les graphiques sont des sorties Python, non des captures Audacity. Le WAV 1 kHz est une validation numérique; l'écoute et le microphone restent à vérifier physiquement.
